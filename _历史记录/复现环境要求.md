# DTI-UIE 复现环境要求清单

论文：*Downstream Task-Inspired Underwater Image Enhancement: A Perception-Aware Study From Dataset Construction to Network Design* (IEEE TIP 2026)
官方代码：`https://github.com/oucailab/DTIUIE`（已克隆到本地 `repro-dti-uie/DTIUIE/`）

## 1. 代码获取情况（任务一结果）

- **代码**：已克隆成功，**不需要梯子**（GitHub 直连失败，已通过 `https://gh-proxy.com/` 镜像完成）。
  - 如需自己重新下载：`git clone https://gh-proxy.com/https://github.com/oucailab/DTIUIE.git`
- **预训练权重 + 数据集**：官方只放在百度网盘，**需要你自己用百度网盘客户端下载**（网盘本身不需要梯子）：
  - DTIUIE 权重：https://pan.baidu.com/s/1A3nXzvM7dLWm6OxAeIHWgw?pwd=nkbi （提取码 `nkbi`），下载后放到 `DTIUIE/checkpoints/`，应为 `DTIUIE_ckpt.pth`
  - TI-UIED 数据集：https://pan.baidu.com/s/1bn0ZRFZYGz1TaNzTwrDwew?pwd=v7fv （提取码 `v7fv`），解压 `tar xvzf TIUIED.tar.gz` 后放到 `DTIUIE/dataset/`
  - 注：README 中数据集的 Google Drive 链接标注 TBD，那个才需要梯子；走百度网盘即可。

## 2. 硬件要求

| 项目 | 要求 |
|---|---|
| GPU | NVIDIA GPU（论文用单卡训练；仅跑测试/推理时显存 ≥ 6 GB 一般够用） |
| GPU 驱动 | 支持 CUDA 11.6 即可（驱动版本 ≥ 510；新驱动向下兼容，不需要单独装 CUDA Toolkit） |
| 内存 | ≥ 16 GB 建议 |
| 磁盘 | 数据集 + 环境约需 20–30 GB 空闲 |

## 3. 软件环境（来自仓库 `environment.yaml`）

> ⚠️ 该 yaml 是在 **Linux** 上导出的（含 `libgcc-ng`、`ld_impl_linux-64` 等包），**不能在你的 Windows 上直接 `conda env create`**。三选一：
> 1. （推荐，最省事）在 Windows 装 **WSL2 (Ubuntu)**，在 WSL 里原样执行 `conda env create -f environment.yaml`；
> 2. 在 Windows 原生 conda 环境里按下面的版本清单手动装（PyTorch 有 Windows cu116 版，可行）；
> 3. 用与作者相同的 Linux 服务器/实验室机器。

核心版本（严格按此组合最稳）：

| 组件 | 版本 |
|---|---|
| Python | 3.9 |
| PyTorch | 1.13.1 (cuda 11.6 build) |
| torchvision | 0.14.1 + cu116 |
| torchaudio | 0.13.1 + cu116 |
| CUDA runtime（conda 内） | 11.6 |
| NumPy | 1.23.5 |
| OpenCV | 4.8.0.76 |

主要第三方库（测试复现路径需要的关键项）：

- 训练/测试：`pytorch-lightning==1.9.4`、`timm==0.9.7`、`einops==0.6.1`、`kornia==0.7.0`、`adamp==0.3.0`、`pytorch-msssim==1.0.0`
- 感知损失/指标：`lpips==0.1.4`、`pyiqa==0.1.11`（UIE 无参考指标如 UIQM/UCIQ 等可能用到）
- 分割评估：`segmentation-models-pytorch==0.4.0`、`pycocotools==2.0.8`、`medpy==0.4.0`
- 常规：`matplotlib`、`pandas`、`scipy==1.9.1`、`scikit-image==0.20.0`、`tqdm`、`tensorboard==2.11`、`visdom==0.2.4`、`lmdb`、`opencv-python-headless`
- 完整清单见仓库 `repro-dti-uie/DTIUIE/environment.yaml` 的 pip 段。

## 4. 隐式下载依赖（可能再需要梯子/缓存）

用权重复现（只做测试）时，脚本在首次运行可能自动联网下载：

- `lpips` 的线性权重（GitHub）；`pyiqa` 指标权重（HuggingFace/GitHub）；`torchvision` 骨干权重（代码里 `pretrained=False` 为主，一般不触发）。
- 若这些下载失败：开梯子跑一次，或提前把缓存文件放到 `~/.cache/torch/hub` 与 `~/.cache/huggingface/`。下载失败时把报错发我，我指认具体文件。

## 5. 目录结构（下载完权重/数据集后应为）

```
DTIUIE/
├── checkpoints/
│   └── DTIUIE_ckpt.pth
├── dataset/
│   ├── train/  {images/, masks_png/, reference/}
│   └── test/   {images/, masks_png/, reference/}
├── underwater_test.py
└── environment.yaml
```

## 6. 复现命令（权重复现路线）

```bash
# WSL/Linux 原环境
conda env create -f environment.yaml
conda activate dtiuie
python underwater_test.py --model model_dtiuie --draw_images
```

本次只做权重复现，**无需跑训练命令** `underwater_train.py`。

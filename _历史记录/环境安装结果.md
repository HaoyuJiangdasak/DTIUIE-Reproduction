# 环境安装结果（2026-10-02）

Miniconda 装在 `D:\miniconda3`（清华镜像安装包，静默安装，未加入 PATH、未注册系统 Python，不影响原有的 Python 3.14）。共创建两个环境，均在 `D:\miniconda3\envs\` 下：

## 1. dtiuie —— 严格按作者 environment.yaml 复现（仅 CPU 可用）

```
torch 1.13.1+cu116 / torchvision 0.14.1+cu116 / torchaudio 0.13.1+cu116
python 3.9.25, numpy 1.23.5, opencv 4.8.0, pytorch-lightning 1.9.4, timm 0.9.7,
kornia 0.7.0, pyiqa 0.1.11, lpips 0.1.4, segmentation-models-pytorch 0.4.0 ...（全部按 environment.yaml 钉版）
```

⚠️ **本机 GPU 用不了这个环境**：RTX 5060 Laptop 是 Blackwell 架构（sm_120），而 torch 1.13.1+cu116 的编译目标最高到 sm_86，GPU 运算会直接卡死（已实测）。该环境只能 CPU 跑，用于和作者版本逐位对齐的严格复现场景。

## 2. dtiuie-gpu —— 同一套依赖，torch 换新（GPU 可用，推荐日常使用）

```
torch 2.7.1+cu128 / torchvision 0.22.1+cu128 / torchaudio 2.7.1+cu128
其余依赖与 dtiuie 完全相同（numpy 1.23.5、lightning 1.9.4、timm 0.9.7 等全部同版）
```

已实测：`torch.cuda.is_available()=True`，GPU matmul / cudnn 卷积正常，sm_120 在支持列表内。lightning 1.9.4 调用新版 torch 时有个 `custom_fwd` FutureWarning，可忽略。
